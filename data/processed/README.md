This directory stores **processed, parsed log sequences** ready for model training.

Files in this directory are generated by running:

```bash
python prototype/pipeline/harden_huflit_train.py
```

Expected outputs:
- `huflit/templates.json` — vocabulary from the custom similarity parser (not Drain3)
- `huflit/{train,val,test}_sequences.npy` — precomputed template-ID windows
- `huflit/{train,val,test}_labels.npy` — heuristic proxy labels (0 = nominal, 1 = proxy anomaly)

The current arrays were split by stream position before windowing. Because dated
backup archives repeat some records, this is not a leakage-free event-time split.
Raw regeneration excludes FortiGate members by default to avoid high I/O; do not
opt in on thermally constrained machines.
