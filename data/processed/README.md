This directory stores **processed, parsed log sequences** ready for model training.

Files in this directory are generated by running:

```bash
python prototype/drain3/log_parser.py
```

Expected outputs:
- `templates.json` — Drain3 template vocabulary
- `sequences_train.npy` — Training sequences (int token IDs)
- `sequences_test.npy` — Test sequences with anomaly labels
- `labels.npy` — Ground truth anomaly labels (0 = Normal, 1 = Anomaly)
