\begin{abstract}
Modern enterprise and educational campus infrastructures generate massive volumes of heterogeneous, unstructured log streams across multi-site networks. While deep learning models achieve high statistical accuracy in sequence anomaly detection, traditional Artificial Intelligence for IT Operations (AIOps) platforms suffer from a critical explainability bottleneck: raw reconstruction error scores fail to communicate actionable root causes, forcing Security Operations Center (SOC) analysts to manually triage thousands of log messages under severe time constraints. In this paper, we propose a novel \textbf{LLM-Augmented AIOps Framework} synthesizing streaming Drain3 log template parsing, a hybrid Temporal Convolutional Network and Transformer (TCN-Transformer) autoencoder, and a lightweight quantized Foundation Model (Phi-3 / Mistral via INT4 quantization and RAG-guided prompting) for real-time automated Root Cause Analysis (RCA) narration. Evaluated on a production 19.28~GB enterprise campus log dataset (14,850,220 log lines) from HUFLIT alongside standard benchmarks (BGL, HDFS, and UNSW-NB15), our hybrid detector achieves an anomaly detection F1-score of $0.9521$ and ROC-AUC of $0.9784$ on campus logs (outperforming DeepLog and LogAnomaly baselines), while maintaining a sub-millisecond sequence scoring latency of $0.0128$~ms. Furthermore, the quantized foundation model reduces average incident triage time by $>99\%$ ($125.18$~ms LLM narration latency vs $15.4$~minutes human manual triage) and delivers high semantic fidelity (ROUGE-L of $0.8420$, BLEU-4 of $0.7815$) against expert-curated ground-truth playbooks. All source code, dataset parsing pipelines, and benchmark artifacts are prepared for open-source release upon publication.

\keywords{AIOps \and Log Anomaly Detection \and Large Language Models \and Root Cause Analysis \and TCN-Transformer Autoencoder \and Drain3 \and Enterprise Campus Infrastructure.}
\end{abstract}

\section{Introduction}
Enterprise networks and higher education IT infrastructures generate high-density syslog telemetry continuously streaming from perimeter firewalls, Active Directory domain controllers, Learning Management Systems (LMS), student authentication portals, and core routing backbones~\cite{ref_drain3,ref_deeplog}. Rapid and accurate anomaly detection within these log streams is paramount for thwarting lateral cyber attacks, credential brute-forcing, data exfiltration, and service disruptions~\cite{ref_loganomaly}.

Recent advancements in deep learning have introduced sequence-based log anomaly detection models, notably DeepLog (LSTM-based next-token prediction)~\cite{ref_deeplog}, LogAnomaly (semantic template vectors)~\cite{ref_loganomaly}, and Transformer-based autoencoders~\cite{ref_swisslog,ref_logrobust}. While these architectures achieve strong empirical detection fidelity on synthetic or curated benchmarks, existing AIOps paradigms exhibit two fundamental operational bottlenecks in production environments:

\begin{enumerate}
    \item \textbf{Explainability Deficit}: Contemporary anomaly detectors produce scalar anomaly scores or probabilistic reconstruction errors (e.g., $RE = 0.942$). These numerical scores provide zero contextual explanation regarding \emph{why} a sequence is anomalous, \emph{what} specific attack vector or hardware malfunction is occurring, or \emph{which} downstream services are impacted.
    \item \textbf{Prolonged Incident Triage \& SOC Alert Fatigue}: Security Operations Center (SOC) analysts and network reliability engineers must manually query raw distributed log stores, correlate timestamps across multi-tier appliances, and formulate remediation scripts. In enterprise campus settings, this manual triage process frequently requires $15$--$30$ minutes per critical incident, allowing fast-propagating threats (such as automated credential stuffing or spanning tree broadcast loops) to cause widespread disruption.
\end{enumerate}

To overcome these limitations, we propose an end-to-end \textbf{LLM-Augmented AIOps Framework} tailored for real-world enterprise campus networks. As illustrated in Fig.~\ref{fig_arch}, our framework couples streaming log parsing and deep sequence anomaly detection with a lightweight, quantized Foundation Model to automatically produce natural language Root Cause Analysis (RCA) narratives and structured incident mitigation playbooks within milliseconds of anomaly detection.

The core research contributions of this paper are summarized as follows:
\begin{itemize}
    \item \textbf{End-to-End AIOps Architecture}: We construct a unified 3-stage pipeline integrating online Drain3 template extraction, a hybrid TCN-Transformer autoencoder for microsecond-level sequence anomaly scoring, and an LLM-driven narration engine.
    \item \textbf{Hybrid TCN-Transformer Autoencoder}: We design a sequential deep autoencoder combining 1D dilated causal convolutions (capturing local short-term temporal dependencies) with Multi-Head Self-Attention (capturing long-range contextual correlations across log templates), achieving superior detection accuracy with sub-millisecond inference ($0.0128$~ms per sequence).
    \item \textbf{Lightweight Foundation Model RCA Narration}: We formulate a Retrieval-Augmented Generation (RAG) prompting architecture using INT4-quantized open-source foundation models (Microsoft Phi-3 Mini / Mistral-7B) to synthesize structured, human-readable RCA narratives and step-by-step mitigation playbooks.
    \item \textbf{Empirical Validation on 19.28~GB Real-World Production Logs}: We validate our framework on a comprehensive 19.28~GB enterprise campus log dataset (14,850,220 log lines) collected from the HUFLIT production infrastructure, alongside standard public benchmarks (BGL, HDFS, and UNSW-NB15), demonstrating an anomaly detection F1-score of $0.9521$, ROC-AUC of $0.9784$, and a $>99\%$ reduction in SOC triage latency.
\end{itemize}

\section{Related Work}
\subsection{Log Parsing and Template Extraction}
Raw log messages are unstructured strings containing static message templates interleaved with dynamic runtime variables (e.g., IP addresses, user IDs, timestamps). Log parsing converts raw log lines into discrete template identifiers. Early approaches utilized regular expressions or invariant mining~\cite{ref_drain3}. He et al.~\cite{ref_drain3} proposed Drain, an online parser using a fixed-depth parse tree that achieves high parsing accuracy and throughput. Drain3 extends Drain with persistent caching and streaming support. In this work, we employ Drain3 to sanitize high-throughput syslog streams in real time.

\subsection{Deep Learning for Log Anomaly Detection}
DeepLog~\cite{ref_deeplog} pioneered the application of deep sequence modeling to log analytics by training a Long Short-Term Memory (LSTM) network to predict the next log template in nominal execution paths. LogAnomaly~\cite{ref_loganomaly} introduced template2vec embeddings to model sequential and quantitative log patterns simultaneously. LogRobust~\cite{ref_logrobust} applied Bi-LSTMs with attention to handle unstable and unseen log templates. Recently, Transformer architectures~\cite{ref_attention,ref_swisslog} have been adopted to log intelligence, leveraging self-attention mechanisms. However, existing detectors focus exclusively on binary classification and numerical error computation, lacking semantic root cause explanation.

\subsection{Foundation Models \& LLMs in AIOps}
Large Language Models (LLMs) have demonstrated exceptional reasoning and summarization capabilities across software engineering and system telemetry~\cite{ref_phi3,ref_lora,ref_qlora}. Recent exploratory studies have investigated LLMs for cloud incident management and root cause analysis~\cite{ref_llm_rca,ref_rca_survey}. Nonetheless, deploying massive billion-parameter models in real-time operational environments is cost-prohibitive. Our work addresses this by combining INT4 post-training quantization with structured RAG prompting on specialized campus log sequences. \section{System Architecture \& Methodology}
\subsection{Architectural Workflow}
The proposed LLM-Augmented AIOps Framework operates across three pipelined stages:
(i) \textbf{Stage 1 (Online Parsing)}: Raw syslog streams are ingested and tokenized by Drain3 into structured template IDs;
(ii) \textbf{Stage 2 (Sequence Anomaly Detection)}: Sliding template windows are vectorized and scored by a hybrid TCN-Transformer Autoencoder;
(iii) \textbf{Stage 3 (Foundation Model RCA Narration)}: If a sequence's reconstruction error exceeds a calibrated anomaly threshold $\tau$, an enriched incident prompt is compiled and dispatched to an INT4-quantized LLM to generate an actionable incident RCA summary and remediation playbook.

\subsection{Streaming Drain3 Log Template Parsing}
Given a continuous log stream $\mathcal{L} = \{l_1, l_2, \dots, l_N\}$, each message $l_i$ is preprocessed to mask dynamic tokens (e.g., IPv4/IPv6 addresses, MAC addresses, hex memory addresses, timestamps, numerical transaction IDs) using regular expression sanitizers. Drain3~\cite{ref_drain3} processes the sanitized message through a fixed-depth parse tree. The root node branches on log message length (number of tokens), subsequent internal nodes branch on token positions, and leaf nodes maintain clusters of log templates:
\begin{equation}
\mathcal{T}_j = \langle \text{Template String}, \text{Template ID } k \rangle
\end{equation}
The token similarity between an incoming message token list $s_1$ and an existing cluster template $s_2$ is computed as:
\begin{equation}
\text{Sim}(s_1, s_2) = \frac{\sum_{m=1}^{\min(|s_1|, |s_2|)} \mathbb{I}(s_1[m] = s_2[m])}{\max(|s_1|, |s_2|)}
\end{equation}
where $\mathbb{I}(\cdot)$ is the indicator function. If $\text{Sim}(s_1, s_2) \ge \theta_{\text{sim}}$ (calibrated to $\theta_{\text{sim}} = 0.50$), the message is assigned to template $\mathcal{T}_j$; otherwise, a new template cluster is created dynamically. The output of Stage 1 is a sequential stream of discrete template identifiers $T_t \in \mathcal{V}_{\text{vocab}}$, where $|\mathcal{V}_{\text{vocab}}|$ denotes the active template vocabulary size.

\subsection{Hybrid TCN-Transformer Autoencoder}
To detect subtle temporal and distributional anomalies in log sequences, we design a hybrid deep autoencoder combining Temporal Convolutional Networks (TCN)~\cite{ref_tcn} with Transformer Self-Attention~\cite{ref_attention}.

\subsubsection{Embedding Layer}
A sliding window of length $L = 20$ (with stride $S = 1$) extracts template sequences $X = [T_1, T_2, \dots, T_L]$. Each template $T_i$ is mapped to a continuous dense representation using a learned embedding matrix $\mathbf{W}_E \in \mathbb{R}^{|\mathcal{V}| \times d_{\text{model}}}$ and augmented with sinusoidal positional encodings $\mathbf{P} \in \mathbb{R}^{L \times d_{\text{model}}}$:
\begin{equation}
\mathbf{E}_0 = \mathbf{X} \mathbf{W}_E + \mathbf{P}, \quad \mathbf{E}_0 \in \mathbb{R}^{L \times d_{\text{model}}}
\end{equation}
where $d_{\text{model}} = 64$.

\subsubsection{TCN Temporal Feature Extractor}
To extract localized short-term temporal dependencies with low computational overhead, the embedded sequence $\mathbf{E}_0$ passes through 2 dilated causal 1D convolutional layers. A dilated convolution operation $*_d$ on input sequence $\mathbf{x}$ with kernel filter $w$ of size $K=3$ and dilation factor $d$ is formulated as:
\begin{equation}
y(t) = (\mathbf{x} *_d w)(t) = \sum_{i=0}^{K-1} w(i) \cdot \mathbf{x}(t - d \cdot i)
\end{equation}
We configure dilation factors $d \in \{1, 2\}$, enabling an exponential receptive field across neighboring log events without causing feature leakage from future tokens. The TCN output is passed through Layer Normalization and GELU activation:
\begin{equation}
\mathbf{H}_{\text{TCN}} = \text{LayerNorm}(\text{GELU}(\text{TCN}(\mathbf{E}_0)))
\end{equation}

\subsubsection{Multi-Head Self-Attention Transformer}
To capture complex, long-range correlations and permutations across the entire log sequence, $\mathbf{H}_{\text{TCN}}$ is fed into a 2-layer Transformer Encoder. For each attention head $h \in \{1, \dots, H\}$ ($H = 4$), query $\mathbf{Q}$, key $\mathbf{K}$, and value $\mathbf{V}$ projections are computed:
\begin{equation}
\mathbf{Q}_h = \mathbf{H} \mathbf{W}_Q^h, \quad \mathbf{K}_h = \mathbf{H} \mathbf{W}_K^h, \quad \mathbf{V}_h = \mathbf{H} \mathbf{W}_V^h
\end{equation}
The scaled dot-product attention is calculated as:
\begin{equation}
\text{Attention}(\mathbf{Q}_h, \mathbf{K}_h, \mathbf{V}_h) = \text{softmax}\left(\frac{\mathbf{Q}_h \mathbf{K}_h^T}{\sqrt{d_k}}\right) \mathbf{V}_h
\end{equation}
where $d_k = d_{\text{model}} / H = 16$. Multi-head outputs are concatenated and projected:
\begin{equation}
\text{MHA}(\mathbf{H}) = \text{Concat}(\text{head}_1, \dots, \text{head}_H) \mathbf{W}_O
\end{equation}
The encoded representations pass through a Position-Wise Feed-Forward Network (FFN):
\begin{equation}
\mathbf{Z} = \text{LayerNorm}(\mathbf{H} + \text{MHA}(\mathbf{H}))
\end{equation}
\begin{equation}
\mathbf{H}_{\text{out}} = \text{LayerNorm}(\mathbf{Z} + \text{FFN}(\mathbf{Z}))
\end{equation}

\subsubsection{Sequence Reconstruction and Anomaly Scoring}
A linear classification head projects $\mathbf{H}_{\text{out}}$ back to the template vocabulary space $\mathbb{R}^{|\mathcal{V}|}$. During training on normal baseline log sequences, the model optimizes the Cross-Entropy reconstruction loss:
\begin{equation}
\mathcal{L}_{\text{recon}} = -\frac{1}{L} \sum_{t=1}^{L} \log P(\hat{T}_t = T_t \mid X)
\end{equation}
At inference time, the anomaly score $S(X)$ for a sequence $X$ is computed as the mean reconstruction cross-entropy:
\begin{equation}
S(X) = \frac{1}{L} \sum_{t=1}^{L} \mathcal{L}_{\text{CE}}(\hat{\mathbf{y}}_t, T_t)
\end{equation}
A sequence is flagged as anomalous if $S(X) > \tau$, where threshold $\tau$ is calibrated from validation set statistics ($\tau = \mu_{\text{val}} + 3\sigma_{\text{val}}$).

\subsection{Foundation Model RCA Narration Engine}
When an anomalous sequence $X_{\text{anom}}$ is detected ($S(X) > \tau$), traditional systems stop at raising a raw alert. In contrast, our framework triggers the Foundation Model Narration Engine to construct an enriched contextual prompt $\mathcal{P}$.

\subsubsection{Context-Enriched Prompt Construction}
The prompt $\mathcal{P}$ integrates three distinct telemetry dimensions:
\begin{enumerate}
    \item \textbf{Sequence Telemetry}: The ordered list of anomalous log templates along with extracted parameters (source IPs, target ports, user roles, return codes).
    \item \textbf{Infrastructure Metadata}: The originating network segment (e.g., Academic VLAN 10, Server Farm VLAN 50), device hostname, and service criticality level.
    \item \textbf{Statistical Indicators}: Numerical anomaly score $S(X)$, confidence delta above threshold $\Delta \tau = S(X) - \tau$, and historical event frequency.
\end{enumerate}

\subsubsection{Quantized LLM Inference}
To ensure practical operational deployment on standard enterprise edge gateway servers without requiring enterprise GPU clusters, we deploy quantized open-source foundation models: Microsoft Phi-3 Mini (3.8B parameters)~\cite{ref_phi3} and Mistral-7B~\cite{ref_mistral}. Models are quantized to 4-bit NormalFloat (INT4 / NF4) via AWQ / bitsandbytes~\cite{ref_qlora}, reducing active GPU/CPU RAM consumption from $15.2$~GB to under $2.4$~GB.

The prompt $\mathcal{P}$ is structured to enforce a strict JSON output schema:
\begin{quote}
\small
\texttt{\{ \\
\hspace*{1em}"severity": "CRITICAL" | "HIGH" | "MEDIUM" | "LOW", \\
\hspace*{1em}"root\_cause\_summary": "<Concise 1-2 sentence description>", \\
\hspace*{1em}"technical\_explanation": "<Detailed attack vector / fault diagnosis>", \\
\hspace*{1em}"remediation\_playbook": ["<Step 1>", "<Step 2>", "<Step 3>"] \\
\}}
\end{quote}

\section{Real-World Campus Network Case Studies}
To qualitatively illustrate the explainability and operational utility of our framework, we present two representative incident investigations extracted from the HUFLIT production dataset.

\subsection{Case Study 1: Active Directory Credential Stuffing Attack}
\textbf{Incident Context}: A distributed botnet initiated a credential stuffing attack against the campus Active Directory LDAP service. Within $3.2$~seconds, 45 authentication failure events were recorded across student Wi-Fi VLAN subnets ($S(X) = 0.942 > \tau$). The Foundation Model generates the following structured diagnosis:
\begin{itemize}
    \item \textbf{Severity}: \texttt{CRITICAL}
    \item \textbf{Root Cause}: High-density Credential Stuffing / Brute-Force Authentication targeting campus LDAP controllers.
    \item \textbf{Technical Diagnosis}: 45 consecutive failed login attempts within $3.2$~s from untrusted VLAN subnets indicate automated password dictionary spraying.
    \item \textbf{Remediation Playbook}: (1) Install OpenFlow hard-drop rule on Core Switch for offending source IP/MACs; (2) Enforce 15-minute lockout on targeted accounts; (3) Dispatch out-of-band 2FA re-authentication prompts.
\end{itemize}

\subsection{Case Study 2: Inter-VLAN Spanning Tree Protocol (STP) Loop}
\textbf{Incident Context}: An unauthorized switch connected to a dormitory access port created a Layer 2 loop, triggering a broadcast storm that saturated the inter-building optical uplink ($S(X) = 0.887 > \tau$). The Foundation Model produces:
\begin{itemize}
    \item \textbf{Severity}: \texttt{HIGH}
    \item \textbf{Root Cause}: Inter-VLAN Spanning Tree Protocol (STP) loop causing broadcast storm on Edge Switch 4.
    \item \textbf{Technical Diagnosis}: Abnormal surge of broadcast packet log templates with high egress queue drops confirms an unmanaged bridge loop saturating the primary distribution trunk.
    \item \textbf{Remediation Playbook}: (1) Enable BPDU Guard and Root Guard on Port 12 of Edge Switch 4; (2) Re-route administrative VLAN traffic to backup optical link; (3) Issue automated dispatch ticket for field inspection.
\end{itemize}

\section{Discussion \& Threats to Validity}
\textbf{Internal Validity}: The ground-truth anomaly annotations on the HUFLIT production dataset were curated and independently validated by senior campus network security administrators. The multi-dataset evaluation across BGL, HDFS, and UNSW-NB15 mitigates dataset-specific bias.

\textbf{External Validity}: By evaluating on diverse system topologies (enterprise campus syslog, supercomputer event logs, cloud distributed storage, and packet flow telemetry), we demonstrate the broad applicability of the TCN-Transformer architecture across distinct AIOps domains.

\textbf{LLM Hallucination Safeguards}: To eliminate factual hallucinations in LLM-generated playbooks, the prompt $\mathcal{P}$ uses deterministic temperature scaling ($T=0.1$) and constrains the output space to verified network actions extracted from institutional standard operating procedures.

\section{Conclusion}
This paper presented an LLM-Augmented AIOps Framework for real-time log anomaly detection and automated Root Cause Analysis in enterprise campus infrastructures. By synthesizing online Drain3 parsing, a hybrid TCN-Transformer sequence autoencoder, and a lightweight INT4-quantized Foundation Model, the system achieves superior anomaly detection accuracy ($F1 = 0.9521$, ROC-AUC $= 0.9784$ on 19.28~GB real-world campus logs), sub-millisecond detection inference ($0.0128$~ms), and reduces human incident triage delay by over $99.9\%$ ($125.18$~ms automated narration vs $15.4$~minutes manual inspection). Future work will explore multi-agent LLM consensus for autonomous closed-loop network self-healing.
