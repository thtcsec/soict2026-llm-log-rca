\begin{abstract}
Modern campus IT infrastructures emit dense, heterogeneous log streams, yet sequence anomaly detectors typically expose only scalar scores that do not explain root causes to operators. We study an AIOps pipeline that couples Drain3 template parsing, a Masked TCN-Transformer sequence autoencoder, and a \emph{designed} local 4-bit LLM+RAG narration stage for campus logs. Detector evaluation uses a measured HUFLIT stream of $1{,}000{,}000$ lines (five days $\times$ $200$k; selective Thang6 extract; large FortiGate CSV members excluded), chronological $80$/$10$/$10$ splits before windowing, nominal-only masked training, and $\tau=\mu_{\mathrm{val}}+3\sigma_{\mathrm{val}}$ across seeds $\{42,101,202,303,404\}$. On the same-split baseline suite, the Masked TCN-Transformer obtains F1 $0.4621 \pm 0.3684$, ROC-AUC $0.7667 \pm 0.0429$, AUPRC $0.8651 \pm 0.0316$, and $0.1028$~ms/seq CPU latency; DeepLog leads ROC-AUC ($0.7808 \pm 0.0201$) while reconstruction AEs lead F1 under this conservative threshold. Labels are proxy signals (HTTP $4$xx/$5$xx, FortiGate deny/block, keywords), not gold SOC annotations. LLM RCA quality is \emph{not} claimed numerically in this revision because the current artifact still uses a mock narration harness.
\keywords{AIOps \and Log Anomaly Detection \and Large Language Models \and Root Cause Analysis \and TCN-Transformer Autoencoder \and Drain3 \and Enterprise Campus Infrastructure.}
\end{abstract}

\section{Introduction}
Enterprise networks and higher education IT infrastructures generate high-density syslog telemetry continuously streaming from perimeter firewalls, Active Directory domain controllers, Learning Management Systems (LMS), student authentication portals, and core routing backbones~\cite{ref_drain3,ref_deeplog}. Rapid and accurate anomaly detection within these log streams is paramount for thwarting lateral cyber attacks, credential brute-forcing, data exfiltration, and service disruptions~\cite{ref_loganomaly}.

Recent advancements in deep learning have introduced sequence-based log anomaly detection models, notably DeepLog (LSTM-based next-token prediction)~\cite{ref_deeplog}, LogAnomaly (semantic template vectors)~\cite{ref_loganomaly}, LogRobust~\cite{ref_logrobust}, and SwissLog~\cite{ref_swisslog}. While these architectures achieve strong empirical detection fidelity on synthetic or curated benchmarks, existing AIOps paradigms exhibit two fundamental operational bottlenecks in production environments:

\begin{enumerate}
    \item \textbf{Explainability Deficit}: Contemporary anomaly detectors typically expose only a scalar anomaly score or reconstruction error. Such numbers provide little contextual explanation of \emph{why} a sequence is anomalous, \emph{what} attack or fault vector is likely, or \emph{which} services are impacted.
    \item \textbf{Prolonged Incident Triage \& SOC Alert Fatigue}: Security Operations Center (SOC) analysts and network reliability engineers must manually query raw distributed log stores, correlate timestamps across multi-tier appliances, and draft remediation steps. In campus settings this manual triage often dominates mean-time-to-repair for multi-service incidents (credential stuffing, broadcast storms), even when the detector already raised an alert.
\end{enumerate}

To overcome these operational challenges, recent 2025--2026 literature---including LLM4Log (145 studies)~\cite{ref_llm4log_survey}, KRONE (ICDE 2026)~\cite{ref_krone_2026}, MaidLog~\cite{ref_maidlog_2026}, Smart Eye (WWW 2026)~\cite{ref_smarteye_2026}, and cloud RCA recommenders~\cite{ref_llm_rca,ref_rca_survey}---already explores LLMs for log analytics and incident narration. The remaining gap for campus operators is narrower: \emph{(i)} measured evaluation on real multi-service campus telemetry (not only public HDFS/BGL), \emph{(ii)} a lightweight local detector that can gate expensive narration, and \emph{(iii)} an edge-oriented RCA \emph{design} that avoids cloud APIs. This paper addresses (i)--(ii) with measured experiments and presents (iii) as an architecture whose quantitative RCA study is still pending.

In this paper, we present a campus AIOps pipeline combining online Drain3 parsing, a Masked TCN-Transformer detector, and a designed local 4-bit LLM+RAG narration stage. We do \emph{not} claim to be the first LLM-for-logs system; our empirical contribution is a hardened campus-stream evaluation with same-split baselines under an explicit, reproducible protocol.

The core contributions are:
\begin{itemize}
    \item \textbf{Campus-stream evaluation protocol}: Chronological $80$/$10$/$10$ partitioning before windowing, nominal-only masked training, $\tau=\mu+3\sigma$ calibration, five seeds, and proxy-label disclosure on a $1{,}000{,}000$-line HUFLIT selective extract.
    \item \textbf{Masked TCN-Transformer detector}: A 15\%-mask sequence autoencoder combining dilated TCN and Transformer encoding, with measured CPU latency $0.1028$~ms/seq on the baseline suite.
    \item \textbf{Same-split baselines}: PCA, DeepLog, LogAnomaly-lite, Transformer AE, and the proposed model under identical templates/splits/thresholding (\texttt{huflit\_baselines.json}).
    \item \textbf{RCA stage as design (unevaluated quantitatively)}: A planned local Phi-3/Mistral INT4 + RAG playbook interface; no ROUGE/expert metrics are reported while the harness remains mocked.
\end{itemize}

\section{Related Work}
\subsection{Log Parsing and Template Extraction}
Log parsing transforms unstructured, free-form text messages into structured event templates by separating constant message strings from dynamic parameters (e.g., IP addresses, ports, timestamps)~\cite{ref_drain3}. Early approaches employed rule-based parsing, fixed-depth parse trees, or streaming sequence-matching techniques~\cite{ref_drain3,ref_spell}. He et al.~\cite{ref_drain3} proposed Drain, an online parser using a fixed-depth parse tree that achieves high parsing accuracy and throughput. Drain3 extends Drain with persistent caching and streaming support. In this work, we employ Drain3 to sanitize high-throughput syslog streams and generate discrete template identifiers for downstream sequence modeling.

\subsection{Deep Learning for Log Anomaly Detection}
Sequence-based anomaly detection models learn temporal transition dynamics over sequences of log templates~\cite{ref_deeplog,ref_loganomaly}. Du et al.~\cite{ref_deeplog} introduced DeepLog, employing Long Short-Term Memory (LSTM) networks to model normal log sequences and flag unexpected subsequent templates as anomalous. Meng et al.~\cite{ref_loganomaly} proposed LogAnomaly, integrating semantic template vectors via FastText to capture semantic similarities. SwissLog~\cite{ref_swisslog} and LogRobust~\cite{ref_logrobust} further address log instability and interleaved execution threads. While deep sequence architectures achieve strong detection precision, they operate as black-box scoring engines: scalar anomaly metrics fail to explain the operational root cause, imposing heavy manual triage overhead on operators.

\subsection{Large Language Models in Log Analytics and RCA}
Recent 2025--2026 surveys, notably LLM4Log~\cite{ref_llm4log_survey}, categorize emerging LLM paradigms in log analytics, identifying key patterns including parser-free pretraining, retrieval-augmented grounding, and modular verifiers. Ma et al.~\cite{ref_krone_2026} proposed KRONE (ICDE 2026), a hierarchical framework utilizing nested LLM modules for log anomaly detection. MaidLog~\cite{ref_maidlog_2026} (ICDE 2026) investigates zero-shot detection on resource-constrained systems, while LogMUSE~\cite{ref_logmuse_2026} and ContraLog~\cite{ref_contralog_2026} examine multi-scale semantic embeddings and contrastive representations. In industry settings, Smart Eye~\cite{ref_smarteye_2026} (WWW 2026) implements a proposer-verifier framework. Cloud incident root-cause recommendation using LLMs has also been explored by Ahmed et al.~\cite{ref_llm_rca} and surveyed in~\cite{ref_rca_survey}. In contrast to systems that call cloud LLM APIs for every event, our \emph{design} gates narration behind a local sequence detector; quantitative edge-LLM RCA results are deferred until a non-mock harness is instrumented.

\section{Methodology}
\subsection{System Architecture Overview}
The proposed LLM-Augmented AIOps Framework operates across three pipelined stages:
(i) \textbf{Stage 1 (Online Parsing)}: Raw syslog streams are ingested and tokenized by Drain3 into structured template IDs;
(ii) \textbf{Stage 2 (Masked Sequence Anomaly Detection)}: Sliding template windows are masked, vectorized, and scored by our Masked TCN-Transformer Autoencoder;
(iii) \textbf{Stage 3 (Designed RCA Narration)}: On alerts, a local 4-bit foundation model \emph{is intended} to retrieve SOP passages and emit a structured JSON playbook; this stage is specified below but not quantitatively evaluated in the current artifact.

\subsection{Masked TCN-Transformer Denoising Sequence Model}
To detect subtle temporal and distributional anomalies without allowing the model to learn trivial identity shortcuts, we formulate our detector as a \textbf{Masked Log Sequence Autoencoder (MLSA)} operating under a denoising autoencoder paradigm: input sequences are corrupted via 15\% dynamic token masking, representations are extracted via a Temporal Convolutional Network (TCN)~\cite{ref_tcn} and Transformer Self-Attention~\cite{ref_attention}, and a linear vocabulary classification head acts as the reconstruction decoder.

\subsubsection{Embedding and Dynamic Masking}
A sliding window of length $L = 20$ with stride $S = 10$ (as used in the measured HUFLIT runs) extracts template sequences $\mathbf{X} = [T_1, T_2, \ldots, T_L]$. During training, 15\% of the template tokens are randomly replaced with a reserved \texttt{[MASK]} token ($ID = |\mathcal{V}|+1$), distinguishing masked positions from sequence padding ($ID = 0$). Padding masks are applied across self-attention layers to prevent padded positions from corrupting contextual representations. Input tokens are embedded into a $d_{\text{model}}$-dimensional continuous vector space:
\begin{equation}
    \mathbf{E} = \text{Embedding}(\mathbf{X}) + \mathbf{P}_{\text{pos}} \in \mathbb{R}^{L \times d_{\text{model}}}
\end{equation}
where $\mathbf{P}_{\text{pos}}$ denotes sinusoidal positional encodings~\cite{ref_attention}:
\begin{equation}
    \mathbf{P}_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right), \quad \mathbf{P}_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)
\end{equation}

\subsubsection{Temporal Convolutional Network (TCN) Layer}
To capture localized temporal patterns across consecutive log events, the embedded sequence $\mathbf{E}$ passes through a stack of 1D dilated causal convolutional layers~\cite{ref_tcn}. For an input sequence $\mathbf{x} \in \mathbb{R}^L$ and a convolutional filter $f: \{0, \ldots, k-1\} \to \mathbb{R}$, the dilated convolution operation with dilation factor $d$ is defined as:
\begin{equation}
    \mathbf{y}(t) = (\mathbf{x} *_d f)(t) = \sum_{i=0}^{k-1} f(i) \cdot \mathbf{x}(t - d \cdot i)
\end{equation}
We configure dilation factors $d \in \{1, 2\}$, enforcing causal convolutions for localized temporal extraction without future feature leakage. Residual connections and layer normalization ensure stable gradient propagation:
\begin{equation}
    \mathbf{H}_{\text{TCN}} = \text{LayerNorm}(\mathbf{E} + \text{ReLU}(\text{DilatedConv1D}(\mathbf{E})))
\end{equation}

\subsubsection{Transformer Multi-Head Self-Attention Encoder}
The output $\mathbf{H}_{\text{TCN}}$ is then fed into a Transformer Encoder block to model long-range inter-template correlations. The encoder utilizes bidirectional self-attention by design to contextualize masked tokens using surrounding sequence events. For queries $\mathbf{Q}$, keys $\mathbf{K}$, and values $\mathbf{V}$:
\begin{equation}
    \text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}}\right) \mathbf{V}
\end{equation}
\begin{equation}
    \text{MHA}(\mathbf{H}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) \mathbf{W}^O
\end{equation}
\begin{equation}
    \text{head}_i = \text{Attention}(\mathbf{H} \mathbf{W}_i^Q, \mathbf{H} \mathbf{W}_i^K, \mathbf{H} \mathbf{W}_i^V)
\end{equation}
The Transformer block applies Post-LayerNorm with residual connections and a two-layer Feed-Forward Network (FFN) with ReLU activations:
\begin{equation}
    \text{FFN}(\mathbf{Z}) = \max(0, \mathbf{Z} \mathbf{W}_1 + \mathbf{b}_1) \mathbf{W}_2 + \mathbf{b}_2
\end{equation}
\begin{equation}
    \mathbf{Z} = \text{LayerNorm}(\mathbf{H} + \text{MHA}(\mathbf{H}))
\end{equation}
\begin{equation}
    \mathbf{H}_{\text{out}} = \text{LayerNorm}(\mathbf{Z} + \text{FFN}(\mathbf{Z}))
\end{equation}

\subsubsection{Masked Reconstruction Objective and Anomaly Scoring}
A linear classification head projects $\mathbf{H}_{\text{out}}$ back to the template vocabulary space $\mathbb{R}^{|\mathcal{V}|}$, serving as the reconstruction decoder. The model is trained to predict original template identities at masked positions via Cross-Entropy loss:
\begin{equation}
    \mathcal{L}_{\text{MLM}} = -\frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \log P(T_i = t_i \mid \mathbf{X}_{\backslash \mathcal{M}})
\end{equation}
During inference, we compute the pseudo-log-likelihood anomaly score across the sequence by masking each valid position $t \in \{1, \ldots, L_{\text{valid}}\}$ in a vectorized batch (excluding padding tokens $ID=0$, with $L_{\text{valid}} \le L$):
\begin{equation}
    S(\mathbf{X}) = \frac{1}{L_{\text{valid}}} \sum_{t=1}^{L_{\text{valid}}} -\log P(T_t = t_t \mid \mathbf{X}_{\backslash \{t\}})
\end{equation}
A validation-calibrated threshold $\tau$ flags anomalous sequences:
\begin{equation}
    \tau = \mu_{\text{val}} + 3 \cdot \sigma_{\text{val}}
\end{equation}
where $\mu_{\text{val}}$ and $\sigma_{\text{val}}$ are the mean and standard deviation of reconstruction loss over nominal validation sequences.

\subsection{RAG-Grounded Foundation Model RCA Narration Engine (Design)}
When $S(X)>\tau$, the intended Stage~3 activates a local RAG+LLM narrator. This subsection specifies the design; it is not backed by measured LLM outputs in the current repository.

\textbf{RAG Knowledge Base \& Vector Retrieval (design)}: The intended grounding path indexes institutional SOP/runbook text with a dense retriever (e.g., BGE) and FAISS, then prompts a local 4-bit model (Phi-3 Mini NF4 / Mistral-7B AWQ INT4) for JSON playbooks. We deliberately do \emph{not} report SOP counts, Hit@2, ROUGE, or LLM latency here: \texttt{rca\_narration.py} in the present artifact still returns template responses rather than measured model outputs.

\textbf{Prompt schema (design only)}: The planned prompt would integrate anomalous templates, infrastructure metadata, and retrieved SOP snippets, requesting JSON fields \texttt{severity}, \texttt{root\_cause\_summary}, \texttt{technical\_diagnosis}, and \texttt{remediation\_playbook}. Claims about measured NF4/AWQ VRAM (e.g., $7.60\rightarrow1.80$~GB) are removed until a non-mock LLM run writes those readings.

\section{Experimental Evaluation}
\subsection{Experimental Setup and Benchmark Datasets}
We conduct a measured empirical evaluation on HUFLIT campus logs:
\begin{enumerate}
    \item \textbf{HUFLIT Campus Logs (Measured Stream)}: From the Thang6 production archive we performed a \emph{selective} extract ($\approx 1.43$~GB of day zip payloads on disk; full uncompressed archive $\approx 21$~GB was \emph{not} fully expanded to avoid I/O thermal spikes). We streamed $1{,}000{,}000$ \texttt{.log} lines balanced across five collection days ($200$k/day) from apache/nginx/portal/aca/careerhub/thuvien and moderate FortiGate logs, skipping FortiGate CSV members and per-member logs larger than $500$~MB. Proxy anomaly labels use HTTP $4$xx/$5$xx, FortiGate deny/block/attack fields, and keyword heuristics (not gold SOC labels). Line-level anomaly rate was $7.96\%$.
    \item \textbf{Public Benchmarks (Deferred)}: Full re-runs of BGL, HDFS, and UNSW-NB15 under the same hardened harness are left to a follow-up revision so that campus numbers remain strictly measured rather than mixed with prior placeholder tables.
\end{enumerate}

\textbf{Strict Chronological Partitioning}: Events are ordered as streamed (day folders chronological), then split $80\%$/$10\%$/$10\%$ \emph{before} sliding windows ($L=20$, step $10$) to prevent cross-partition leakage. Training uses masked token modeling ($15\%$ mask ratio) on \emph{nominal} windows only. Threshold $\tau=\mu_{\mathrm{val}}+3\sigma_{\mathrm{val}}$ is computed on nominal validation reconstruction scores. Seeds: $42,101,202,303,404$.

\textbf{Hardware \& Software Setup}: Experiments in this revision were executed on CPU (PyTorch $2.8.0$+cpu) with an available NVIDIA GeForce RTX 4050 laptop GPU noted for future CUDA re-runs. Software: Windows 11, Python $3.13$, scikit-learn $1.9$.

\section{Discussion \& Threats to Validity}
\textbf{Internal \& External Validity}: Proxy labels and chronological skew (test sequence anomaly rate $80.5\%$) make $\mu+3\sigma$ F1 brittle (near-zero for DeepLog/PCA despite AUC$\approx 0.74$--$0.78$). Gold SOC labels and day-balanced test sampling are required before operational claims. Measured baselines live in \texttt{huflit\_baselines.json}; LLM RCA metrics remain withheld until non-mock inference is instrumented.

\textbf{Ethics \& Data Privacy}: Production campus syslog streams were collected under authorized institutional IT oversight from HUFLIT. Analysis used selective extracts and streaming reads; large FortiGate CSV members were not fully expanded in this revision. Telemetry should remain pseudonymized (IP hashing, credential redaction) prior to any broader release.

\textbf{Hallucination Risk}: Until measured LLM runs exist, remediation playbooks must not be treated as validated operator guidance.

\section{Conclusion}
We presented an LLM-Augmented AIOps framework design for campus log anomaly detection and RCA narration, with a hardened detector evaluation on $1{,}000{,}000$ HUFLIT lines and measured same-split baselines (PCA, DeepLog, LogAnomaly-lite, Transformer AE, Masked TCN-Transformer). Under chronological partitioning and $\tau=\mu+3\sigma$, reconstruction AEs reach mean F1 $\approx 0.46$ while DeepLog leads ROC-AUC ($0.7808\pm0.020$); absolute gains over Transformer AE are small. Future work will add gold labels, day-balanced tests, CUDA timing, and non-mock LLM RCA evaluation.
